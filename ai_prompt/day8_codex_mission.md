# Day 08. 회원 서비스 만들기 (User Management)

거의 모든 온라인 서비스에는 사용자의 신원을 확인하고 개인화된 환경을 제공하기 위한 **"회원가입과 로그인(User Management)"** 기능이 필수적으로 포함되어 있습니다. 그러나 개발 입문 단계에서 백엔드 데이터베이스 암호화(Hashing), 토큰 기반 인증(JWT), 세션 보안 쿠키 같은 기술적 매커니즘에만 매몰되다 보면 정작 가장 중요한 **"사용자가 쉽고 안전하며 막힘없이 가입하고 로그인할 수 있는 최적의 사용자 경험(UX)"**을 놓치기 쉽습니다.

Day 8 과정은 회원 인증 기능을 기계적으로 코딩하는 법을 배우는 날이 아니라, **"사용자가 우리 서비스를 최초로 접하고 회원이 되는 생애 첫 여정(Onboarding Journey)을 AI와 함께 설계하고 검토하는 날"**입니다. 회원 기능의 기획 단계에서부터 사용자의 가입 심리적 장벽을 낮추고(Task 01), 가입 양식의 복잡도와 불필요한 입력 단계를 도려내며(Task 02), 중복 가입이나 비밀번호 분실 시의 예외 대책 등 빠진 요소를 촘촘히 보완(Task 03)하는 실습을 진행합니다.

학습자는 Codex AI를 유능한 서비스 기획 어드바이저이자 모의 사용자(Persona User)로 기용하여 처음 가입하는 고객의 고충을 채집하고(Mission 01), 구축한 회원 서비스 구조의 완성도를 다차원적 품질 지표로 평가받아 개선하는(Mission 02) 협업 프로세스를 학습하게 됩니다. 이를 통해 비개발 직군도 설계의 전 과정을 직관적으로 이해하고 참여할 수 있는 실무 밀착형 사용자 중심 가이드를 획득합니다.

# Task 01. 회원 기능 설계하기 (User Feature Planning)

## 1. 스토리 및 실습 배경

스타트업의 공동 창업자들이 모여 새로운 상담 예약 플랫폼에 필요한 회원 가입 방식을 논의하고 있습니다. 한 팀원은 "보안을 위해 이메일 인증, 휴대폰 인증, 주소와 상세 프로필을 가입할 때 다 받아야 합니다"라고 주장했고, 다른 팀원은 "가입 단계가 5초만 넘어가도 고객의 70%는 이탈합니다. SNS 1초 간편 로그인만 넣어야 합니다"라며 맞섰습니다. 의견이 엇갈리며 어떤 기능을 먼저 만들고 어떤 기능을 나중으로 미뤄야 할지 갈피를 잡지 못하고 시간만 흘러갔습니다.

회원 서비스 기획의 첫 단추는 필요한 기능 목록을 정리하고, 개발 리소스와 사용자 편의성 간의 균형을 고려하여 우선순위를 획득하는 것입니다. 이번 실습에서는 Codex AI에게 가상의 서비스 사양을 전달하고, 필수 뼈대 회원 기능(가입/로그인)과 선택 확장 기능(SNS 연동, 마이페이지)을 깔끔하게 분류하고 우선순위를 도출하는 기능 설계서 작성법을 학습합니다.

# Task 02. 사용자 관점에서 회원 기능 검토하기 (User Flow Review)

## 1. 스토리 및 실습 배경

온라인 쇼핑몰 앱 배포 이후 가입 페이지만 들어오면 구매 전환을 하기도 전에 사용자들이 앱을 삭제하는 심각한 현상이 발생했습니다. 원인을 찾기 위해 가입 화면을 켜보니, 아이디, 비밀번호, 닉네임 외에도 '우편번호 검색', '가입 경로', '추천인 ID', '마케팅 SMS 동의(필수 아님)' 등 15가지가 넘는 입력 칸이 화면에 빽빽하게 나열되어 있었고, 하나라도 틀리면 기존에 입력했던 비밀번호가 지워지며 붉은 경고가 표시되었습니다.

개발자 입장에서는 데이터베이스 구조에 맞게 폼 입력을 촘촘히 유도했다고 생각하겠지만, 사용자에게 이것은 회원가입을 포기하고 이탈하게 만드는 '가입 장벽(Friction Block)'입니다. 이번 실습에서는 Codex AI를 활용하여 회원가입과 로그인 절차 전반의 동선을 사용자 관점에서 전수 분석하고, 입력 단계를 대폭 간소화하여 회원 유치 효율을 극대화하는 UX 개선 보고서를 작성하는 요령을 학습합니다.

---

## 2. 학습 목표

* 복잡한 회원가입 절차(Input Forms) 속에서 사용자의 인지적 과부하와 이탈을 유발하는 불필요 요소를 지목할 수 있다.
* 로그인 과정을 단순화(예: 아이디/비밀번호 찾기 동선 최소화)하는 TO-BE 유저 플로우 대안을 제시할 수 있다.
* AI의 사용성 분석 의견을 바탕으로 사용자 친화적인 동선 개선 기획을 수립할 수 있다.

---

## 3. 실습 미션

학습자는 기존에 설계했던 복잡한 가입 양식 명세를 담은 `day8_signup_spec.md`를 준비하고, Codex Client에게 사용성 검토를 의뢰합니다.

> "제공된 회원가입 사양서 `day8_signup_spec.md`를 분석하여, 처음 가입하는 일반 유저가 마주칠 사용성 저해 요소를 3가지 지적해 주세요. 그리고 입력 양식 개수를 줄이고 오류 시 비밀번호가 리셋되는 현상을 예방하는 개선안 보고서(User Flow Report)를 제안해 주세요."

---

## 4. 결과물 예시

Codex는 입력 사양을 오디팅하여 가용성 저해 지점과 대안 동선을 담은 보고서를 리턴합니다.

### User Flow Review Report (사용자 흐름 보고서)

#### 1. 인지 마찰 지점 (Friction Points)
- **과도한 필수값 요구**: 가입 즉시 필요 없는 '상세 주소'와 '추천인 ID'를 가입 필수 단계로 묶어 입력 중도 포기를 유발함.
- **가이드 피드백 부재**: 비밀번호 규칙(특수문자 포함 등)이 사용자가 입력 창에 입력하기 전에 미리 안내되지 않아 3번 이상 실패하는 장벽 생성.

#### 2. 가입 프로세스 개선 제안 (TO-BE Flow)
- **1단계 (즉시 가입)**: 이메일과 비밀번호, 닉네임 입력만으로 가입 즉시 승인 (3초 완료).
- **2단계 (추가 입력)**: 상세 주소 및 프로필 사진은 대시보드 진입 후 첫 예약 신청 시점에 입력하도록 단계 분할 유도(Friction Delay).

---

## 5. AI 활용 포인트

* **이탈 장벽 정량화**: "15개 입력창을 채울 때의 평균 피로 속도"와 같은 기획 단계에서의 인지 한계점을 사용자 행동 심리에 근거해 논리적으로 설명해 줍니다.
* **동선 분할(De-coupling) 설계**: 한 번에 모든 것을 받으려는 욕심을 버리고, 가입과 프로필 완성 단계를 시점별로 분리하는 스마트한 화면 연결 시나리오를 제시합니다.

# Task 03. 회원 기능 점검하기 (User Feature Review)

## 1. 스토리 및 실습 배경

로그인과 가입 화면 코딩을 마친 주니어 개발자가 "회원 기능이 완벽하게 돌아갑니다!"라고 자랑스럽게 보고했습니다. 그러나 배포 후 몇 시간 뒤, 한 명의 이메일 계정으로 중복 가입 요청이 전송되자 동일 메일의 유저가 두 명 적재되어 결제 시 엉뚱한 사용자의 내역으로 잡히는 중대한 정합성 버그가 터졌습니다. 또한 임시 비밀번호를 발송할 때 기존 사용자의 계정 활성화 여부를 체크하지 않아 비활성화된 계정에도 메일 발급이 마구 연사되는 장애가 이어졌습니다.

단순 로그인 화면의 버튼 클릭 성공 여부와 회원 계정 생명주기(Life Cycle)의 정합성을 보장하는 것은 차원이 다른 문제입니다. 이번 실습에서는 Codex AI를 감사관(Auditor)으로 배정하여, 구현 완료한 가상 회원 서비스 파일 `day8_user_service.js`를 대상으로 이메일 중복 확인, 특수문자 주입 보안, 비밀번호 찾기 임시 세션 만료 등 놓치기 쉬운 계정 보안 및 정합성 예외 사항을 찾아 점검표를 구축합니다.

---

## 2. 학습 목표

* 가입 및 인증 로직 동작 성공 이면에 내재된 데이터 정합성 결함(중복 가입 등)을 발굴할 수 있다.
* 비밀번호 재설정 및 계정 잠금(Lockout) 조건 등 보안 품질에 관계된 비즈니스 룰을 설명할 수 있다.
* AI의 기능 오디팅 소견을 참고하여 가상의 회원 로직 누락 방지 점검 보고서를 작성할 수 있다.

---

## 3. 실습 미션

학습자는 중복 검사나 가드가 빠져 보안상 취약한 `day8_user_service.js` 파일을 업로드하고, Codex Client에 완성도 검사를 요구합니다.

> "제공된 `day8_user_service.js` 회원 가입 및 로그인 스크립트를 감사하여 1) 중복 가입 체크 누락 위험, 2) 비밀번호 분실 시 기존 패스워드 즉시 폐기 등의 결함을 도출하고, 서비스 안정성을 높이기 위한 유효 가드가 보강된 최종 자바스크립트 개선본을 제안해 주세요."

## 4. 결과물 예시

Codex는 취약한 가입 로직을 진단하고 정합성이 통제된 코드를 반환합니다.

### 1) 취약점 보강 개선 소스
```javascript
// AS-IS: 중복 검사 없는 단순 데이터 삽입
// TO-BE: 중복 이메일 체크 및 보안 예외 처리 추가
const userDatabase = [];

function registerUser(email, password, nickname) {
  // 1. 중복 가입 가드 (Duplicate Guard)
  const isDuplicated = userDatabase.some(user => user.email === email);
  if (isDuplicated) {
    return { success: false, message: "이미 가입된 이메일 주소입니다." };
  }
  
  // 2. 입력 형식 가드 (Email Validation)
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(email)) {
    return { success: false, message: "올바른 이메일 형식이 아닙니다." };
  }
  
  // 3. 사용자 데이터 안전 적재
  const newUser = { email, password, nickname, status: 'active' };
  userDatabase.push(newUser);
  return { success: true, user: newUser };
}
```

# Mission 02. 회원 서비스 품질 평가하기 (Usability Metric Evaluation)

## 1. 미션 개요

최종적으로 다듬어진 가상 회원 로직의 전체 동작 시퀀스를 다차원적 품질 지표(조작 편의성, 에러 예방성, 정보 가시성) 기준으로 Codex에 객관적 품질 검사를 요청하고, 강점을 격려받음과 동시에 추가하면 서비스 가치가 급상승할 추천 기능 로드맵을 획득합니다.

---

## 2. 세부 수행 과제

1. **최종 코드 감사 요청**: 완성된 가입 및 스토리지 가드 스크립트를 전송하고 다차원 사용성 정량 평가를 지시합니다.
2. **장단점 도출 분석**: Codex가 제시한 평점 지표(각 5점 만점 기준)와 강점(중복 이메일 가드 완벽), 치명적 약점(로그인 실패 시 아이디가 틀렸는지 비밀번호가 틀렸는지 과도하게 친절하게 적어 해커에게 힌트를 주는 보안 약점 등)을 분석합니다.
3. **추천 보완 장치 구현**: AI가 추천한 모듈 보완 대책을 확인해 소스코드에 적용합니다.
4. **품질 평가서 저장**: 종합 점수 매트릭스가 작성된 `day8_usability_evaluation.md` 파일을 제출합니다.
