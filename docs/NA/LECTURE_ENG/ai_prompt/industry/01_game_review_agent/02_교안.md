# Game user review analysis Agent teaching plan

## Introduction

Start with a question.

- “If 1,000 game reviews are posted per day, what should the management team look at first?”
- “When praise reviews, bug reports, and billing complaints are mixed, what criteria should we use to divide them?”

Key message:

> The purpose of the review analysis agent is not to summarize the review nicely, but to enable the operation team to decide the next action.

## Key Description

### Review classification categories

- Bugs/Errors: Unable to connect, crashes, payment errors, compensation not paid
- Balance: character performance, difficulty, matching, excessive repetitive play
- Billing: price, probability item, payment satisfaction, refund request
- Content request: Request to add new modes, characters, events, and stories
- Praise: Graphics, story, control, operational satisfaction
- Other/Needs confirmation: Reviews with unclear meaning or insufficient information

### Agent output structure

Recommended output items:

- Review Summary
- classification
- Emotional Tone
- Urgency
- Reason for judgment
- Referral follow-up

## Practice progress

1. Review samples are read and classified by humans first.
2. Write classification criteria for each team.
3. Write a prompt including classification criteria to the Agent.
4. Enter 5 reviews and check the results.
5. Supplement the classification criteria by adding ambiguous reviews.
6. Transform the final results into operational actions.

## Feedback points for instructors

- Instead of lumping it into one “negativity”, divide it into game management categories.
- Be sure to print out the reasons for the decision.
- Urgency should be viewed based on operational impact rather than emotional intensity.
- When reviews are complex, encourage them to be divided into main categories and subcategories.

## Closing question

-What reviews should the operations team check today?
-What types of reviews are most likely to result in incorrect automatic classification?
- If this Agent is used for actual operational tasks, what additional data is needed?
