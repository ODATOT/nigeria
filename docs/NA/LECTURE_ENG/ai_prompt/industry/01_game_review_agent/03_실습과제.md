# Game user review analysis agent practice assignment

## Assignment goal

We design an agent that automatically classifies game user reviews and suggests follow-up actions for the operation team.

## Review Sample

| number | Reviews |
|---:|---|
| 1 | When I log in after the update, it crashes right away. I didn't even receive compensation. |
| 2 | The new character designs are great and the story is immersive. |
| 3 | The odds of winning were so low that I lost the motivation to pay. |
| 4 | The boss difficulty suddenly increases, making it difficult for new users to progress. |
| 5 | I wish there were more cooperative content that you can play with friends other than guild battles. |
| 6 | The game is fun, but the loading time is long and it heats up a lot. |

## Steps to perform

1. Define review classification categories.
2. Write judgment criteria for each category.
3. Create an Agent prompt.
4. Input review samples to generate classification results.
5. Add urgency and follow-up.
6. Find misclassified cases and improve prompts.
