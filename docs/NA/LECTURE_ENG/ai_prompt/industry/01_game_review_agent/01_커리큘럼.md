# Game user review analysis agent curriculum

## Course Overview

- Topic: Game user review/VOC analysis agent design
- Target audience: Learners interested in game planning, operation, QA, and community management
- Goal: Design an Agent that classifies user reviews, determines priorities, and connects them to operational actions.
- Recommended time: 3 hours
- Main tool: Antigravity or LLM-based agent design tool

## Learning Objectives

- Game user reviews can be classified into bugs, balance, charging, content requests, praise, etc.
- Classification criteria and reasons for judgment can be clearly reflected in the prompt.
- Review analysis results can be converted into operational priorities and response actions.
- The input, processing, and output structure of the review analysis agent can be designed.

## Chasi configuration

| steps | Topic | Core activities | output |
|---:|---|---|---|
| 1 | Understanding game VOC | Linking Review Types to Operational Decisions | Review classification rubric |
| 2 | Designing Classification Prompts | Category, reason for judgment, definition of urgency | Classification Prompt |
| 3 | Workflow design | Enter review → Sort → Priority → Action suggestion | Agent flow chart |
| 4 | Testing and Improvement | Ambiguous review, complex review, extreme expression test | Improvement Prompt |
| 5 | Announcement | Sharing ways to utilize the operation team's perspective | Page 1 Design Summary |

## Recommended practice scenarios

The mobile RPG game operation team must check app store and community reviews every day. Because there are so many reviews that it is difficult for people to read them all, the agent automatically classifies the reviews, determines the level of urgency, and summarizes the issues that the operations team needs to check.

## Final output

- Review classification table
- Review analysis agent prompt
- Classification result table by review
- Operational action proposal table
- Agent design summary

## Evaluation criteria

| Item | standards |
|---|---|
| Classification criteria | Have you defined categories that fit the game operation context? |
| Reason for judgment | Is the explanation of the classification results acceptable? |
| Priority | Have you considered urgency and impact? |
| feasibility | Did the operations team suggest actions that can be used right away? |
