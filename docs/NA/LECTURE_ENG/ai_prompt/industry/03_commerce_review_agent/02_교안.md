# Commerce product review improvement agent teaching plan

## Introduction

Start with a question.

- “Are product reviews just customer impressions or improvement data?”
- “Can I find a hint on how to fix the detail page in the review?”

Key message:

> The purpose of the Commerce Review Agent is not just to classify reviews, but to create improvements that increase purchase conversion and customer satisfaction.

## Key Description

### Review classification categories

- Quality: durability, materials, performance, finish
- Delivery: speed, packaging, damage, incorrect delivery
- Price: Comparison of cost-effectiveness, discounts, and competitive products
- Usability: size, installation, operation, convenience
- CS: Exchange, refund, response speed
- Repurchase/recommendation: satisfaction, willingness to recommend

### Improvement Action Type

- Supplementation of detailed page
- Modify option name
- Size/usage information added
- Added FAQ
- Create CS response template
- Request for product or delivery policy improvement

## Practice progress

1. Read product information and review samples.
2. Sort reviews into categories.
3. Find the cause of repeated complaints.
4. Create phrases that need to be supplemented on the detail page.
5. Create draft FAQs and CS responses.
6. Prioritize improvements that will impact purchase conversions.

## Feedback points for instructors

- Classify based on criteria that influence purchase decisions rather than simple positive/negative.
- Distinguish between the emotions of the review and actual improvement points.
- The text on the detail page should be reviewed to ensure that it does not become an exaggerated advertisement.
- FAQs should be written close to customer question sentences.

## Closing question

- Which reviews can have the greatest impact on sales?
- What information can be added to the details page to reduce inquiries?
- To what extent should CS responses be automated and where should humans begin to review them?
