# Commerce Product Review Improvement Agent Curriculum

## Course Overview

- Topic: Agent design that analyzes product reviews to improve detail pages, FAQs, and CS response
- Target: Commerce MD, marketer, CS manager, learner interested in product planning
- Goal: Categorize product reviews and derive actions necessary to improve purchase conversion and customer satisfaction.
- Recommended time: 3 hours

## Learning Objectives

- Product reviews can be classified into quality, delivery, price, usability, CS, and repurchase intention.
- The cause of dissatisfaction in the review can be converted into a point for improvement on the detailed page.
- Customer questions and complaints can be drafted into FAQs and CS responses.
- Agent flows suitable for commerce operation tasks can be designed.

## Chasi configuration

| steps | Topic | Core activities | output |
|---:|---|---|---|
| 1 | Understanding review data | Buyer Review Type Categorization | Review classification rubric |
| 2 | Analysis of causes of complaints | Identifying repetitive issues and purchasing barriers | Improvement points table |
| 3 | Detailed page improvement | Product description, FAQ, disclaimer text suggestions | Detailed page text |
| 4 | Generate CS Response | Drafting a Situational Response | CS response template |
| 5 | Announcement | Share conversion improvement perspectives | Agent design summary |

## Recommended practice scenarios

Reviews of new products at online shopping malls are piling up. Agent analyzes reviews to find points of customer inconvenience and suggests improvements to detail page text, FAQs, and CS answers.

## Final output

- Review classification table
- Product review analysis result table
- Details page improvement text
- FAQ/CS Response Draft
- Agent design summary

## Evaluation criteria

| Item | standards |
|---|---|
| Review Category | Have you established classification standards suitable for commerce work? |
| Improved Connections | Does review analysis lead to improvements in detail pages or CS? |
| Output Utilization | Can MD, marketers, and CS managers use it right away? |
| Exception handling | Do you deal with malicious reviews, mixed reviews, and reviews that lack information? |
