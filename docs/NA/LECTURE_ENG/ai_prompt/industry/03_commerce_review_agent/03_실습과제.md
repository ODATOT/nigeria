# Commerce Product Review Improvement Agent Practice Task

## Assignment goal

Design an agent that analyzes product reviews and drafts detailed page improvement text, FAQs, and CS responses.

## Product information

```text
Product name: Foldable wireless mini fan
Features: Portable, 3-stage wind speed adjustment, USB-C charging, up to 8 hours of use, desk mountable
Price range: 29,900 won
Main customers: Students, office workers, customers who engage in a lot of outdoor activities
```

## Review Sample

| number | Reviews |
|---:|---|
| 1 | It's small and light, so it's great to carry around when commuting to work. |
| 2 | The wind was weaker than expected, so it was disappointing to be outside. |
| 3 | The charging terminal is USB-C, so it's convenient, but I don't think the battery lasts up to 8 hours. |
| 4 | The box was crushed during shipping. The product was okay. |
| 5 | I use it well in the office because it is easy to stand on my desk. |
| 6 | It's a bit noisy, so it's difficult to use in a quiet library. |

## Steps to perform

1. Classify reviews into quality, delivery, price, usability, CS, and repurchase intention.
2. Sort out the causes of repeated complaints.
3. Write guidance text to be added to the details page.
4. Create three FAQs.
5. Create two draft CS responses.
6. Set priorities for improvement.
