# Content IP Goods Planning Agent Practice Task

## Assignment goal

Design an agent that analyzes game or movie IP and suggests product ideas, product evaluation, and sales phrases.

## IP Sample

```text
IP name: Starlight Route
Genre: Science Fiction Adventure Game
Worldview: A story about humanity sailing through space in search of a lost star map.
Main characters: Novice navigator Rian, maintenance robot Momo, legendary captain Arden
Symbol elements: star map, old spaceship rudder, blue star, exploration badge
Fandom points: Momo's cute way of speaking, Rian's growth narrative, and the collection experience to complete the star map.
```

## Steps to perform

1. Extract the core appeal and symbolic elements of the IP.
2. Create 10 goods ideas.
3. Evaluate based on fan appeal, production difficulty, price suitability, and IP uniqueness.
4. Select the top three ideas.
5. Create a detailed plan for the final product.
6. Create detailed page text and sales strategy.
