# Content IP Goods Planning Agent Teaching Plan

## Introduction

Start with a question.

- “Are the goods that fans want to buy simply products with logos?”
- “What elements of the IP will be attractive when turned into a product?”

Key message:

> IP Goods Agent is not a tool that lists many products, but a tool that translates points that fans want to remember and own into products.

## Key Description

### IP Analysis Element

- Worldview
- Main characters
- Symbol
- Famous lines or scenes
- fandom memes
- Need for emotional ownership

### Goods evaluation criteria

- Fan attractiveness
- Production difficulty
- Cost and price suitability
- Everyday usability
- Limited edition possibility
- IP uniqueness

### Sales Strategy Elements

- Target customers
- Product name
- Key reasons for purchasing
- Price range
- Sales Channel
- First sentence of detail page
- Bundle configuration

## Practice progress

1. Read the IP sample and extract key elements.
2. Generate more than 10 goods ideas.
3. Select the top three based on evaluation criteria.
4. Create a detailed plan for the final product.
5. Create detailed page key phrases and bundle strategy.
6. Each team announces sales possibilities.

## Feedback points for instructors

- Ask whether the IP is unique rather than just listing common goods.
- Be sure to write down the fan’s emotional reason for purchasing.
- Ideas that are too difficult to produce make us question how to make them a reality.
- Sales text must maintain a worldview, but product information must also be clear.

## Closing question

-Why does this product have to be this IP?
-Why do fans want to own this product?
-What more information is needed to sell it as a commerce product?
