# Content IP Goods Planning Agent Curriculum

## Course Overview

- Topic: Goods product planning agent design using game/movie IP
- Target audience: Students interested in content planning, IP business, merchandising, and commerce
- Goal: Design an agent that analyzes the world view of the IP and fan characteristics to suggest goods ideas and sales strategies.
- Recommended time: 3 hours

## Learning Objectives

- The core appeal, characters, world view, and fandom elements of the IP can be structured.
- You can propose goods product ideas that fit the characteristics of the IP.
- You can design target customers, price range, sales channels, and detailed page messages.
- You can create an Agent Workflow that connects content and commerce.

## Chasi configuration

| steps | Topic | Core activities | output |
|---:|---|---|---|
| 1 | IP analysis | Extracting worldview, characters, and fandom points | IP Analysis Table |
| 2 | Generating Goods Ideas | Product group and concept proposal | Goods candidate list |
| 3 | Product evaluation | Evaluation of production difficulty, fan appeal, and price range | Priority table |
| 4 | Sales Strategy Design | Detailed page, bundle, channel strategy | Sales Strategy Plan |
| 5 | Announcement | Sharing IP goods plan | Agent design summary |

## Recommended practice scenarios

We plan to release goods for fans using game or movie IP. The agent analyzes IP information, creates product candidates, evaluates marketability, and even suggests sales phrases.

## Final output

- IP analysis table
- Goods Idea Candidate
- Product evaluation table
- Detailed page key phrases
- Agent design summary

## Evaluation criteria

| Item | standards |
|---|---|
| Understanding IP | Did it reflect the worldview and fandom points well? |
| Productivity | Is this a product idea that can actually be sold? |
| Differentiation | Is IP uniqueness revealed in the product?
| Sales Strategy | Are the targets, prices, channels, and messages specific? |
