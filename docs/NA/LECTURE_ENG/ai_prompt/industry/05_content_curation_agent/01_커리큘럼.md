# Content Recommendation Curation Agent Curriculum

## Course Overview

- Topic: Design of game/movie/product recommendation agent based on user tastes
- Target: Learners interested in content platforms, commerce recommendations, and service planning
- Goal: Design an agent that receives information about the user's tastes, recommends games, movies, and products together, and explains the reason for the recommendation.
- Recommended time: 3 hours

## Learning Objectives

- User preference information can be structured into recommendation conditions.
- Recommendation criteria for games, movies, and products can be designed separately.
- Reasons, cautions, and alternatives can be presented along with the recommendation results.
- You can design the conditional branch and output format of the recommended agent.

## Chasi configuration

| steps | Topic | Core activities | output |
|---:|---|---|---|
| 1 | Taste data structuring | Summary of user profiles and preferences | Taste Input Table |
| 2 | Recommendation standard design | Definition of genre, atmosphere, price, usage situation | Recommendation rubric |
| 3 | Create Curation | Game·movie·product bundle recommendation | Recommended result table |
| 4 | Strengthening explainability | Write reasons for recommendation and exclusion | Description Prompt |
| 5 | Announcement | Sharing curation concept | Agent design summary |

## Recommended practice scenarios

When users enter their preferences and situations, the agent recommends games, movies, and related products to enjoy on the weekend as a curated set. The recommendations include reasons and alternatives.

## Final output

- User preference input table
- Recommendation rubric
- Curation result table
- Recommended description prompt
- Agent design summary

## Evaluation criteria

| Item | standards |
|---|---|
| Taste Structuring | Was the user input well converted into recommendation conditions? |
| Recommendation consistency | Are games, movies, and products connected by one concept? |
| explainability | Is the reason for recommendation specific and understandable? |
| conditional branching | Do results vary depending on budget, time, and genre preference? |
