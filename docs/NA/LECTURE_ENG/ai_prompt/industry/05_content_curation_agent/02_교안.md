# Content Recommendation Curation Agent Teaching Plan

## Introduction

Start with a question.

- “How are good recommendations different from popular lists?”
- “Will users be more satisfied if they understand why they received this recommendation?”

Key message:

> Recommendation Agent is not a tool that provides the correct answer, but a tool that provides explanatory suggestions for options that suit the user's tastes and situations.

## Key Description

### Taste input elements

- Preferred genre
- Disliked elements
- Hours of use
- budget
- Alone/together
- Desired emotion
- Recently liked content

### Recommended output elements

- Recommended items
- Reason for recommendation
- suitable situation
- Things to note
- Alternative recommendations
- Connected products or follow-up content

### Conditional branch example

- Recommend light content if time is short
- Recommend free or low-cost products if your budget is low
- If you dislike horror, we recommend an alternative with less thriller intensity.
- Recommend cooperative games or popular movies if you are with friends

## Practice progress

1. Read the user profile sample.
2. Structure recommendation conditions.
3. Create recommendations for games, movies, and products.
4. Create a curation set.
5. Add reasons for recommendation and exclusion.
6. Test with different user profiles and compare the differences in results.

## Feedback points for instructors

- Avoid simply recommending popular content.
- Make the recommendation reason directly linked to user input.
- Be sure to reflect the elements and constraints you dislike.
- Commerce products serve a role that complements the content experience.

## Closing question

- Do the recommendation results sufficiently reflect the user's situation?
- What problems will arise if only the results are presented without a reason for recommendation?
- What are the risks if the recommended agent makes a mistake in the actual service?
