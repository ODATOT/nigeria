# Content Recommendation Curation Agent Practice Assignment

## Assignment goal

We design a curation agent that receives user tastes and situations and recommends games, movies, and products.

## Sample user profile

```text
user A
- I have about 3 hours free on weekend evenings.
- I like immersive stories.
- I dislike content that is too cruel or scary.
- Plan to enjoy it alone
- Budget is less than 30,000 won
- Recent good content: Emotional science fiction movies, narrative-centered adventure games
```

## Steps to perform

1. Extract recommendation conditions from the user profile.
2. Create recommendations for each game, movie, and product.
3. Present the recommended results as first priority and alternative options.
4. Explain the reason for the recommendation in connection with the user conditions.
5. Write down the types not recommended and the reason for exclusion.
6. Create different user profiles and test the differences in results.
