# Movie marketing point extraction agent lesson plan

## Introduction

Start with a question.

- “For the same movie, will the promotional text change depending on who it is shown to?”
- “What information is needed for marketing in the synopsis?”

Key message:

> A movie marketing agent is not a tool to summarize the plot, but a tool to find reasons for the audience to react.

## Key Description

### Synoptic analysis elements

- Genre
- main characters
- Core conflict
- Background and world view
- Emotional Tone
- Differentiated materials
- Expected target audience

### Audience response analysis elements

- Popular elements: acting, directing, music, immersion, message
- Dissatisfaction factors: speed of development, probability, ending, inconsistency with genre expectations
- Expressions that can be used for promotion
- Misunderstandings to watch out for

### Output structure

- One line positioning
- Target audience
- 3 key appeals
- 5 poster copies
- 5 SNS short form phrases

## Practice progress

1. Provide a sample movie synopsis.
2. Extract genre, conflict, emotion, and target audience.
3. Enter a sample of audience reviews and share favorable comments and complaints.
4. Derive marketing points based on analysis results.
5. Create poster text and SNS text.
6. Remove and improve phrases that do not match the tone of the movie.

## Feedback points for instructors

- Don't just summarize the plot, but turn it into a point of appeal for the audience.
- Check whether the copy conforms to the grammar of the genre.
- Requires specific emotions rather than general expressions such as “interesting” or “moving.”
- Avoid targeting your target audience too broadly.

## Closing question

-What is the strongest selling point of this film?
- Is it suitable for some audiences and not for others?
-What parts of the copy created by AI must be reviewed by humans?
