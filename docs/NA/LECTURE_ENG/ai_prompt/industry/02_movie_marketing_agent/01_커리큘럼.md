# Movie Marketing Point Extraction Agent Curriculum

## Course Overview

- Topic: Extracting movie marketing points using synopsis and audience reaction Agent
- Target audience: Students interested in film planning, distribution, publicity, and content marketing
- Goal: Design an agent that structures movie information and derives target audiences, key copies, and promotional points.
- Recommended time: 3 hours

## Learning Objectives

- Genre, conflict, characters, emotions, and audience appeal can be extracted from the synopsis.
- You can classify favorable and dissatisfied elements from audience reviews.
- You can create copy and short-form text that can be used to promote movies.
- You can design a workflow that goes from analysis to marketing proposals.

## Chasi configuration

| steps | Topic | Core activities | output |
|---:|---|---|---|
| 1 | Structuring movie information | Extract synoptic elements | Synopsis Analysis Table |
| 2 | Analysis of audience reaction | Review sentiment and keyword classification | Summary of audience reactions |
| 3 | Deriving marketing points | Summary of targets, appeals, and points of differentiation | Marketing Points Table |
| 4 | Create copy | Create poster phrases and SNS phrases | Copy Candidate |
| 5 | Announcement | Sharing promotional strategies | Agent design summary |

## Recommended practice scenarios

Independent film distributors are preparing promotional strategies before release. Agent receives synopsis and audience reviews and suggests target audience, key emotions, promotional copy, and short-form content text.

## Final output

- Synopsis analysis table
- Audience reaction analysis table
- Marketing point extraction prompt
- Candidate for promotional copy
- Agent design summary

## Evaluation criteria

| Item | standards |
|---|---|
| Analysis Accuracy | Did you extract the key conflicts and emotions of the synopsis well? |
| Understanding the audience | Did you specifically suggest the target audience and appeal? |
| Copy Quality | Did you create a phrase that fits the tone and genre of the movie? |
| Workflow design | Are the analysis and proposal stages logically connected?
