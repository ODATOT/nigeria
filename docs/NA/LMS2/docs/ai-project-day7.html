설계 검토 (gstack) 

/plan-eng-review
우리 팀의 USER_FLOW.md, 화면 명세, DATA/API 계약, TRACEABILITY.md 를 검토해 줘.
새 기능은 추가하지 말고 다음만 찾아줘:
1. 핵심 흐름에서 빠진 상태(빈 · 오류 · 복구)
2. 화면에는 있지만 DATA/API 가 없는 기능
3. 측정할 수 없는 수용 기준
4. 내일 하루 안에 구현하기에 너무 큰 범위
결과는 표(문서 / 문제 / 제안 / 심각도)로, 아직 코드를 작성하지 마.
