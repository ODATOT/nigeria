Features

Five things a plain chat can't do

✅

Accept or reject

Each AI edit appears as a diff in the editor. You approve it.

Why: nothing changes without you.

📋

Plan as a file

The AI writes docs/plans/REQ-001.md. You edit it, then say "build it".

Why: you approve before code exists.

📎

@-mention files

@SPEC.md points the AI at the exact file.

Why: less guessing.

🌐

Run next to code

Terminal + browser + console (F12) side by side.

Why: see bugs yourself.

🕘

Source Control

Every change and commit, one click away.

Why: undo is always possible.

"Don't learn all the buttons. Learn the loop: plan file → edit → build → accept the diff → run it → commit."
