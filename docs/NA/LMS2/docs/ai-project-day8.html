Day 8 mission

끝까지 동작하는 흐름 하나

오늘 끝날 때 누군가 처음부터 끝까지 클릭해서 따라갈 수 있어야 합니다.

Split & integrate

나눠서 만들고 자주 합친다

통합을 미룰수록 충돌과 버그가 커집니다.

REQ ID로 분담한 사람 = 한 REQ (파일 충돌 최소화)
feature 브랜치feat/REQ-004-option-select
작은 커밋기능 하나 = 커밋 하나

Analogy · 졸로프 라이스

자주 섞고 자주 맛보기 = 자주 통합

Build cycle

한 번에 REQ 하나씩, 같은 순서로

AI에게 '앱 만들어 줘'가 아니라 범위를 잠근 요청을 보냅니다.

Verify

만든 다음엔 두 가지 눈으로 확인

코드 관점과 사용자 관점은 다른 문제를 찾습니다.

/reviewdiff의 결함 · 보안 · 규칙 위반 (코드 관점)
