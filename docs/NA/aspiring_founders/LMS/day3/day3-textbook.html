실습 3. 핵심 기능과 결과 화면 완성 (Antigravity)

📌 Antigravity: PROJECT.md의 첫 번째 핵심 사용자 흐름을 결과 화면까지 완성해 주세요. 기본, 로딩, 빈 값, 성공, 오류 상태를 문서의 완료 기준에 맞게 처리합니다. 실제 외부 서비스가 필요하면 교육용 Mock 데이터를 사용하고 이를 명시합니다.

5. Day 3 자율형 실습 주제 2종

[자율 주제 A] 단순 CRUD 노트 앱 MVP v0.1 구현

📌 Antigravity 자율 주제 A: 단순 노트 앱 MVP를 구현해 주세요. Must 기능: 1. 텍스트 노트 작성 후 저장 버튼 (localStorage 사용) 2. 저장된 노트 목록 조회 3. 노트 삭제 버튼 상태 처리: 입력 빈값 안내, 노트 없을 때 빈 상태 메시지 완료 기준: 노트 생성→조회→삭제 흐름이 새로고침 후에도 유지될 것.

[자율 주제 B] 계산기 또는 단위 변환기 웹 도구

📌 Antigravity 자율 주제 B: BMI 계산기 웹 앱을 구현해 줘. Must 기능: 1. 키(cm)와 몸무게(kg) 입력 폼 2. BMI 수치 계산 및 결과 표시 (저체중/정상/과체중/비만 판정) 3. 재입력 버튼 완료 기준: 올바른 입력 시 BMI 수치와 판정 텍스트가 화면에 표시될 것.
