실습 2. Antigravity로 선택 트랙 기능 구현

📌 Antigravity: 갱신된 PROJECT.md와 CHANGE_REQUEST_DAY4.md를 기준으로 선택 기능을 구현해 주세요. 보존 조건에 있는 기존 흐름은 변경하지 않습니다. 작업 전 영향 파일을 보고하고, 완료 후 변경 파일·신규 기능·기존 기능 확인 방법·남은 위험을 정리해 주세요.

실습 3. UX·오류·예외 개선 (MVP v1.0)

📌 Antigravity: MVP v1.0의 완성도를 높여 주세요. - 빈 값: 해당 필드 아래 안내 메시지 표시 - 처리 실패: 기술 오류 대신 친절한 설명 + 다시 시도 버튼 - 데이터 없음: 첫 데이터 생성 유도 - 기술 오류 원문을 사용자에게 그대로 노출하지 않는다 - 실패 시 사용자 입력값 유지

📌 Codex: PROJECT.md, CHANGE_REQUEST_DAY4.md, VALIDATION_DAY3.md와 현재 구현을 비교해 회귀 검증해 주세요. 기존 Must와 신규 Must를 구분하고 각 항목을 Pass/Fail/Manual Check로 평가해 VALIDATION_DAY4.md에 기록합니다. Fail에는 재현 단계, 기대 결과와 실제 결과를 포함합니다.

5.5 Day 4 자율형 실습 주제 2종

[자율 주제 A] 기존 목록에 필터·검색 기능 추가

📌 Antigravity 자율 주제 A: 기존 노트 앱 목록 화면에 필터와 검색 기능을 추가해 줘. 추가할 기능: 1. 키워드 검색: 노트 제목/내용으로 실시간 필터링 2. 정렬: 최신순/오래된순 토글 버튼 보존 조건: 기존 노트 생성·조회·삭제 흐름은 변경하지 않는다. 예외: 검색 결과 없을 때 '검색 결과가 없습니다' 메시지 표시 완료 기준: 검색어 입력 시 실시간으로 목록이 필터링될 것.

[자율 주제 B] 에러 상태 및 빈 값 UX 전면 개선

📌 Antigravity 자율 주제 B: 서비스의 모든 에러 상태를 사용자 친화적으로 개선해 줘. 처리: 빈값 안내, 처리 실패 친절한 설명, 데이터 없음 유도, 중복 알림 원칙: - 오류 메시지에 항상 다음 행동(버튼)을 포함할 것 - 실패 시 사용자 입력값을 유지할 것
