💡 AI Tool Role Division & Standard Pipeline

Codex and Antigravity collaborate within the exact same workspace directory through a structured engineering pipeline.

Step 1. Planning & Spec
Codex (Markdown Spec)
Structure raw ideas into build-ready, unambiguous requirements in PROJECT.md.
Step 2. Service Development
Antigravity (Code Generation)
Autonomously scaffold project files, UI layouts, and interactive full-stack code strictly from specs.
Step 3. QA & Testing
Codex (Quality Audit)
Audit implementation against acceptance criteria and identify discrepancies or bugs.
Step 4. Iterative Polish
Codex ➔ Antigravity
Update specs in markdown first, then safely prompt Antigravity to iterate on the codebase.
