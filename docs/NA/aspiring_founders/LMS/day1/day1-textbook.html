AI 개발 도구와 작업 방식 익히기

1. 교육 개요 및 핵심 학습 목표

본 자율 학습 교재는 개발 경험이 없거나 적은 예비창업자가 AI 개발 도구인 Codex와 Antigravity를 활용하여 생각을 명확한 문서로 만들고, 실제 동작하는 웹 서비스 MVP로 만드는 표준 가이드입니다.

🔄 AI 기반 개발 파이프라인
Codex(요구사항 MD 작성) ➔ Antigravity(서비스 구현) ➔ Codex(테스트·검증) ➔ Codex(MD 보완) ➔ Antigravity(코드 수정)

2. 폴더, 파일, 그리고 절대경로

AI 기반 개발에서 가장 중요한 원칙은 두 AI 도구가 동일한 프로젝트 로컬 절대경로를 바라보고 있어야 한다는 점입니다.

📁 my-project/
├── 📄 README.md 프로젝트 목적 및 개요
├── 📄 PAGE_REQUIREMENTS.md Codex 화면 요구사항 명세
├── 📄 VALIDATION.md Codex 검증 체크리스트
└── 🌐 index.html Antigravity 웹 애플리케이션

3. 도구별 역할 분담

도구 주요 역할 핵심 산출물
Codex 생각과 아이디어를 요구사항 MD로 작성, 테스트 및 품질 검증 PAGE_REQUIREMENTS.md, VALIDATION.md
Antigravity 작성된 MD를 분석하여 프로젝트 자동 생성 및 UI/UX 코드 구현 index.html 등 실제 동작하는 웹 코드
웹 브라우저 실제 사용자 화면과 버튼 클릭 동작 결과를 직접 검증 브라우저 실행 화면

4. 프롬프트 작성의 3요소

AI에게 지시할 때 대답의 품질을 결정하는 3가지 핵심 요소입니다.

  1. 목표 (Goal): 구체적으로 생성할 결과물 파일이나 화면 지정
  2. 조건 (Constraints): 디자인 모드, 폰트, 포함 및 제약 사항
  3. 완료 기준 (Acceptance Criteria): 사용자가 브라우저에서 무엇을 확인해야 성공인가?

5. 실습 단계별 프롬프트 가이드

실습 1. Codex용 환경 구성 프롬프트

📌 Codex: 이 프로젝트 폴더(my-project)의 기본 역할을 정의해 줘. 프로젝트 목적은 "AI 개발 도구를 활용한 기본 웹 서비스 실습"이야. 기본 README.md 파일을 생성하고 설명 구조를 작성해 줘.

실습 2. Codex용 PAGE_REQUIREMENTS.md 생성 프롬프트

📌 Codex: PAGE_REQUIREMENTS.md 파일을 생성해 줘. 내용: "예비창업자 프로필 및 서비스 소개 페이지" 1. 제목: My Startup Pitch 2. 상단: 창업자 이름, 한 줄 소개, 핵심 분야 태그 3. 중단: 해결하려는 문제, 해결책 카드 2개 4. 하단: 문의하기 버튼 5. 조건: 다크 모드 스타일, Pretendard 폰트 6. 완료 기준: 브라우저에서 올바르게 표시될 것.

실습 3. Antigravity용 서비스 구현 프롬프트

📌 Antigravity: PAGE_REQUIREMENTS.md 파일을 읽고, 명시된 요구사항을 만족하는 index.html 웹페이지를 만들어 줘. - Pretendard 폰트와 깔끔한 다크 UI를 적용해 줘. - 상단 프로필, 문제/해결책 카드, 하단 문의 버튼을 모두 포함해야 해. - 작성 완료 후 완성된 웹페이지를 바로 브라우저에서 실행할 수 있게 해줘.

실습 4. Codex용 품질 검증 프롬프트

📌 Codex: index.html 코드를 검토하고 PAGE_REQUIREMENTS.md 내용과 비교해 줘. 1. 누락된 요구사항이나 잘못 구현된 부분이 있는지 점검해 줘. 2. VALIDATION.md 파일을 새로 만들고 테스트 체크리스트(통과/미통과)를 작성해 줘. 3. 누락 부분이 있다면 PAGE_REQUIREMENTS.md에 수정 요청사항으로 추가해 줘.

5.5 Day 1 자율형 실습 주제 2종 (Autonomous Practice Projects)

기본 따라하기 실습을 마친 학습자가 처음부터 스스로 요구사항 MD를 작성하고 서비스를 구축할 수 있는 선택 도전 주제입니다.

[자율 주제 A] AI 기반 개인 포트폴리오 & 경력 소개 웹페이지

  • 작성 명세: PORTFOLIO_REQUIREMENTS.md
  • 핵심 구성: 프로필 헤더, 기술 스택 태그 5개, 주요 프로젝트 카드 3개, 이메일 문의 및 소셜 링크
📌 Codex 자율 주제 A 프롬프트 예시: PORTFOLIO_REQUIREMENTS.md 파일을 생성해 줘. 내용: "개발자/기획자 개인 포트폴리오 원페이지 웹사이트" 1. 제목: My Professional Portfolio 2. 상단: 이름, 프로필 이미지 영역, 핵심 역량 한 줄 요약 3. 중단: 기술 스택 태그 5개, 주요 프로젝트 카드 3개 (제목, 설명, 사용 기술) 4. 하단: 이메일 문의하기 버튼 및 소셜 링크 5. 조건: 모던 다크 UI, Pretendard 폰트 적용 6. 완료 기준: 브라우저에서 프로젝트 카드가 반응형으로 정렬될 것.

[자율 주제 B] 신규 아이템 출시 전 랜딩 페이지 & 사전 신청 웹 서비스

  • 작성 명세: LAUNCH_REQUIREMENTS.md
  • 핵심 구성: 헤드라인, 해결 과제 및 혜택 카드 3개, 사전 알림 신청 폼, 신청 완료 팝업 알림
📌 Codex 자율 주제 B 프롬프트 예시: LAUNCH_REQUIREMENTS.md 파일을 생성해 줘. 내용: "신규 서비스 사전 알림 신청 랜딩 페이지" 1. 제목: Service Pre-launch 2. 상단: 서비스 로고, 강렬한 헤드라인 문구, 기대 효과 3가지 카드 3. 중단: 사전 신청 입력 폼 (이름, 이메일 주소, 사전 등록 버튼) 4. 하단: 서비스 Q&A 3개 항목 accordion 5. 조건: 깔끔한 푸른색 톤 UI, 반응형 렌더링 6. 완료 기준: 이메일 입력 후 사전 등록 버튼 클릭 시 성공 메시지가 팝업될 것.
