Core Concept 01

🔄 AI 개발의 기본 파이프라인

Codex (요구사항 MD 작성) ⬇️ Antigravity (MD 분석 ➔ 서비스 코드 구현) ⬇️ Codex (문서 대비 구현 결과 검증 & 테스트) ⬇️ Codex (검증 결과를 MD에 반영) ⬇️ Antigravity (변경된 MD 기준으로 서비스 수정)
  • AI가 만든 결과는 완성품이 아니라 검토 대상입니다.
  • 한 번에 전체를 만들기보다, 확인 가능한 작은 단위로 진행합니다.
AI 기반 Web App MVP 개발 과정 Slide 4 of 14
🎤 발표자 노트: Codex는 기획/문서/검증의 주 도구이고, Antigravity는 코드 구현의 주 도구라는 파이프라인을 강조합니다.
Core Concept 02

📁 폴더, 파일, 그리고 절대경로

  • 프로젝트 폴더: 문서, 코드, 이미지가 함께 위치하는 공간
  • 절대경로: 내 컴퓨터 안에서 해당 폴더의 고유 주소
  • 동일 경로: Codex와 Antigravity에서 반드시 같은 경로를 열어야 변경 사항이 공유됩니다.
📁 my-project/
├── 📄 README.md 프로젝트 목적
├── 📄 PAGE_REQUIREMENTS.md Codex 요구사항 명세
├── 📄 VALIDATION.md Codex 검증 보고서
└── 🌐 index.html Antigravity 구현 코드

Prompting Guide

💡 좋은 프롬프트 작성의 3요소

1. 목표 (Goal)
어떤 결과물(파일, 화면, 기능)을 만들어야 하는가?
2. 조건 (Constraints)
디자인 스타일, 폰트, 기술 조건, 포함 및 금지 사항
3. 완료 기준 (Criteria)
사용자가 어떤 클릭과 렌더링을 확인해야 성공인가?
AI 기반 Web App MVP 개발 과정 Slide 7 of 14
🎤 발표자 노트: "그냥 잘 만들어줘"가 아닌 목표, 조건, 완료 기준 3요소를 프롬프트에 담도록 지도하세요.
Security & Safety

⚠️ 안전한 작업과 보안 원칙

  • 🔒 보안 원칙: API 키, 개인정보, 비밀번호를 프롬프트에 절대 입력하지 않습니다.
  • 🔍 변경 파일 확인: AI가 변경한 파일 목록을 적용 전에 실행 창에서 확인합니다.
  • 💾 복구 포인트: 정상 동작하는 시점에 복사본을 남겨 원복 가능하게 합니다.
