1. Overview & Core Principles

💡 Day 2 Core Principle: One complete end-to-end user flow is 10x better than five half-baked features.

On Day 2, we write zero application code. We use Codex to thoroughly draft and audit specifications. The finalized PROJECT.md becomes the single source of truth that Antigravity executes on Day 3.

2. Idea-Centric vs Problem-Centric Framing

Starting with tech features risks building products nobody needs. A sharp problem statement must specify: User Persona, Context, Pain Point, and Desired Transformation.

Idea-Centric (❌)Problem-Centric (✅)
"AI-Powered Travel Planner App""Solo travelers spend 2+ hours manually calculating itineraries and routes across fragmented apps."
"Restaurant Recommendation App""Solo diners needing to find quality dinner spots within 10 minutes without decision paralysis."

3. Designing the Core User Flow

Define the linear value chain: Input ➔ Processing ➔ Result ➔ Value.

Input: Preferences, budget, available hours Processing: Optimization of route sequences Result: User reviews and saves customized itinerary Core Screen Sequence: Landing ➔ Preferences ➔ Generation ➔ Result View ➔ Saved Itinerary
