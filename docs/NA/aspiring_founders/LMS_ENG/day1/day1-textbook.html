2. Folders, Files, and Shared Workspace Absolute Paths

The golden rule of AI-assisted engineering is that both AI tools must operate within the exact same shared local workspace directory.

📁 my-project/
├── 📄 README.md Project Overview & Setup
├── 📄 PAGE_REQUIREMENTS.md Screen UI & Acceptance Spec (Codex)
├── 📄 VALIDATION.md Automated QA Checklist (Codex)
└── 🌐 index.html Deployed Web Application (Antigravity)

3. Tool Roles & Responsibilities

Tool Primary Role Core Output
Codex Structure thoughts into markdown specs, generate QA audit checklists PAGE_REQUIREMENTS.md, VALIDATION.md
Antigravity Analyze specifications to generate complete project structure & UI code index.html and running interactive web code
Web Browser Inspect interactive UI rendering, touch targets, and button triggers Live Browser Viewport

4. The 3 Essential Elements of Prompt Engineering

Three pillars that determine prompt clarity and generation quality:

  1. Goal: Explicitly name the target file, component, or screen to generate.
  2. Constraints: Specify design themes (dark mode), fonts, layout grids, and restrictions.
  3. Acceptance Criteria: Measurable verification criteria visible in the live browser.

5. Step-by-Step Lab Prompt Guide

Lab 1. Environment Setup Prompt (Codex)

📌 Codex: Define the core purpose of this workspace folder (my-project). Project Goal: "Foundational AI Web App Development Practice for Aspiring Founders". Create a clear `README.md` file detailing the workspace purpose and tech stack.

Lab 2. Specification Generation Prompt (Codex)

📌 Codex: Create `PAGE_REQUIREMENTS.md` with the following specifications: Context: "Founder Profile & Startup Service Landing Page" 1. Header: Founder Name, One-line Tagline, Domain Tags 2. Body: Problem Statement, 2 Solution Cards with Icons 3. Footer: Interactive Contact / Pitch Deck Button 4. Constraints: Modern Dark Theme, Pretendard / Sans-serif Font 5. Acceptance Criteria: Renders cleanly across mobile and desktop.

Lab 3. Autonomous Code Generation Prompt (Antigravity)

📌 Antigravity: Read `PAGE_REQUIREMENTS.md` and generate a complete, responsive `index.html` file meeting all specs. 1. Design: Modern dark theme with subtle glassmorphism and modern typography. 2. Styling: Inline clean CSS supporting mobile & desktop viewports. 3. Components: Profile header (avatar, name, bio, tags), problem/solution cards, and interactive modal/contact button. 4. Acceptance Criteria: Single index.html that runs immediately in any browser.

Lab 4. Automated QA Audit Prompt (Codex)

📌 Codex: Review `index.html` and compare against `PAGE_REQUIREMENTS.md` acceptance criteria. 1. Check for missing elements, unclosed tags, or unresponsive layouts. 2. Create `VALIDATION.md` containing an automated PASS/FAIL test checklist. 3. If any requirement is missing, append explicit change requests to `PAGE_REQUIREMENTS.md`.

6. Security Principles & FAQ

⚠️ Security & Safety Guidelines
- Never paste raw API keys, secrets, or private passwords into prompts.
- Always review file diffs before and after AI execution.
- Keep backups of stable versions for effortless rollback.
