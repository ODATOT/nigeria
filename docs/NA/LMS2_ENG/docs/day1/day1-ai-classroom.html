Key Summary Notes

Day 1 Summary

Today's key goals

On Day 1 you'll practice automating requirements docs with Codex Client and learn the basics of wireframing screens in Figma.

  • AI-based requirements specs: use Codex Client to automate everything from cleaning meeting notes to sending a Gmail report
  • Figma basics: understand Figma's key tools and interface, like frames and auto layout
  • Landing & Product Grid Setup: set up a standard 12-column responsive grid (coming soon)
  • Hero & Components Design: sketch a persuasive hero area and build reusable component variants (coming soon)
  • Prototyping & Test: connect wireframe nodes and share a clickable demo to test usability (coming soon)
Learning tip: ask the AI chatbot on the right questions like "What is Figma auto layout?" or "How do I separate normal and exception flows in Codex?"
