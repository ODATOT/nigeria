1. Story and lab background

After many ups and downs, you finished code where the screen shows and there are no errors. You think it's all done since it works, but your team lead looks at the code and sighs: "There are too many duplicate functions here, and I can't tell what the variable names mean. If we release it like this, in a month even you will struggle to fix it."

A working program is only the 'minimum requirement' of development; if the code is messy and tangled like spaghetti, it holds back business growth. In this lab, Codex reviews your code, groups duplicate logic into reusable functions and applies clear Naming Conventions, tidying it into Clean Code with the best readability and maintainability.

2. Learning goals

  • Understand the structural difference between complex code that just works and readable, maintainable code.
  • Pull out duplicate features and hard-coded values into a reusable structure.
  • Rename variables/functions clearly and refactor based on AI code review suggestions.
