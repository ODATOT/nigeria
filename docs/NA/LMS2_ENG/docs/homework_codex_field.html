Codex Field Assignments 10

PBL assignments that solve recurring work in real organizations with Codex and connected apps. Each mission goes in this order: understand the situation → design safe automation → run → human approval → submit evidence. You're graded not just on the result, but on spotting and controlling moments when AI is wrong or oversteps its permissions.

10 missionsAutomating planning, dev and ops work
60–120 minSuggested time per mission
2–4 appsCodex-linked tools per mission
Evidence-based submissionRun logs, links, decision records

Assignment steps

  1. Read the persona and work situation in the card's View details.
  2. Connect the apps you need, and use only practice projects, channels and docs.
  3. Copy the given prompt and add your own data and approval conditions.
  4. Review Codex's suggestions, and approve write actions yourself after a preview.
  5. Submit the required outputs together with codex_review.md.

Safety rules before running

Don't run directly on real customer or production data. For actions that change outside state — deleting, deploying, sending email, creating tickets — always check the target and changes first. Apps that aren't connected must finish plugin connection first.
