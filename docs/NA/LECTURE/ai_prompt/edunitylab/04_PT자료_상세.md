# [Day 6] 개발 (AI와 함께 화면 만들기) (Slides 91–102)
- **Slide 91. 6일차 오프닝 & 16차시 안내**: [AI와 함께 화면 만들기] 세션 소개 및 대시보드 그리드 뼈대 기획.
- **Slide 92. 도입 질문**: 빈 에디터 화면을 열고 첫 줄을 코딩할 때의 막막함과 AI 페어프로그래머 도움의 필요성.
- **Slide 93. 핵심 설명**: 와이어프레임 텍스트 명세(`day6_layout_spec.md`)를 HTML skeleton과 Grid/Flex CSS로 신속하게 빌드하는 원리.
- **Slide 94. 실습 진행 Task 01**: Codex Client를 통한 대기/승인/완료 카드 UI 초안 생성 및 뼈대 프로젝트 구조 설계.
- **Slide 95. 실습 진행 Task 02**: `TypeError: Cannot read properties of undefined (reading 'map')` 디버깅 및 안전 옵셔널 체이닝(`?.`) 가드문 작성.
- **Slide 96. 실습 진행 Task 03**: `day6_dirty_code.js` 리팩토링 - 중복 HTML 생성부를 공통 유틸 함수(`createCardTemplate`)로 분리.
- **Slide 97. Mission 01**: JSON 파싱 중 만나는 `SyntaxError: Unexpected token <` 진단서(`day6_error_report.md`) 작성.
- **Slide 98. Mission 02**: 전역 변수 오염을 최소화하고 상태 변경을 IIFE 혹은 상태 객체 맵핑 모듈로 교환한 `day6_code_review.md` 리포팅.
- **Slide 99. 정리 및 회고**: 6일차 핵심 요약 및 7일차 예고.

# [Day 7] 개발 (AI와 함께 기능 완성하기) (Slides 100–111)
- **Slide 100. 7일차 오프닝 & 19차시 안내**: [AI와 함께 기능 완성하기] 세션 소개 및 기능 연동.
- **Slide 101. 도입 질문**: 화면 구성은 다 되었는데 로그인 버튼이나 예약하기를 눌러도 아무 동작도 일어나지 않는 정적 화면의 단절.
- **Slide 102. 핵심 설명**: 이벤트 리스너(Submit, Click)를 적용해 사용자 입력 데이터를 추출하고 로컬 스토리지에 동기화해 적재하는 흐름.
- **Slide 103. 실습 진행 Task 01**: `day7_unconnected_feature.html`에 가입 완료 조건 검증 및 localStorage 적재 스크립트 연동.
- **Slide 104. 실습 진행 Task 02**: 뒤로 가기 복귀 시 목록 카테고리 정보 유실을 차단하기 위한 SessionStorage 캐싱 상태 관리.
- **Slide 105. 실습 진행 Task 03**: 동일인 동일 시간 예약 중복 삽입 결함을 방어하기 위한 로딩 `disabled` 락 및 과거 날짜 신청 차단.
- **Slide 106. Mission 01**: 로딩 피드백(Spinner) 누락, 스토리지 용량 예외를 오디팅하여 `day7_service_audit.md` 리포트 빌드.
- **Slide 107. Mission 02**: 50대 초보 가상 유저 페르소나와의 E2E 시나리오 롤플레잉 결과를 기록한 `day7_e2e_validation.md` 검증서.
- **Slide 108. 정리 및 회고**: 7일차 핵심 요약 및 8일차 회원 관리 안내.

# [Day 8] 회원 서비스 만들기 (User Management) (Slides 112–123)
- **Slide 112. 8일차 오프닝 & 22차시 안내**: [회원 서비스 만들기] 세션 소개 및 온보딩 여정.
- **Slide 113. 도입 질문**: 데이터베이스 규칙만 생각하다가 15개 가입 인풋 필드를 배치해 고객을 전부 쫓아낸 가입 피로 마찰 지점.
- **Slide 114. 핵심 설명**: 가입 즉시 승인(1단계)과 첫 예약 신청 시 상세 정보(2단계)로 분할 처리하여 온보딩 장벽을 걷어내는 설계법.
- **Slide 115. 실습 진행 Task 01**: 필수 가입/로그인(Must)과 SNS연합/탈퇴(Nice)를 브레인스토밍하고 우선순위 테이블 작성.
- **Slide 116. 실습 진행 Task 02**: 복잡한 회원 가입 스펙(`day8_signup_spec.md`)의 Friction Block을 진사하여 단축 개선안 수립.
- **Slide 117. 실습 진행 Task 03**: `day8_user_service.js` 중복 메일 가입 차단 정합성 검증 및 Brute Force 해킹 공격을 방어하는 단일 통합 실패 에러 문구 교정.
- **Slide 118. Mission 01**: 60대 실버 가상 페르소나의 비밀번호 특수문자 조합 불통 당혹감을 실시간 유효성 인디케이터로 수렴한 개선서.
- **Slide 119. Mission 02**: 조작성, 회복성, 보안 다차원 품질 등급 Usability Scorecard(`day8_usability_evaluation.md`) 채점.
- **Slide 120. 정리 및 회고**: 8일차 핵심 요약 및 9일차 결제 관리 예고.
