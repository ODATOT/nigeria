1. 스토리 및 실습 배경

대시보드와 가입, 예약 연동 로직의 기본적인 조립을 마치고, 작동 상의 누락 구간이나 디테일한 입력 장벽이 남았는지 Codex를 '서비스 QA 파트너' 삼아 다차원 완성도 감사를 요청하고 종합 보완 지침을 획득합니다.

2. 학습 목표

  • 작성한 자바스크립트 소스코드의 전반적 품질을 AI에 의뢰하여 정량 점검받는다.
  • 서버 통신 시 사용자에게 로딩 상태(Spinner)를 주는 것이 왜 중요한지 이해한다.
  • 로컬스토리지 용량 한계 초과 등 예외 상황 처리(try-catch)의 중요성을 파악한다.

🛠️ 실제 따라 하기 실습 가이드

  1. 실습용 파일 생성: 아래 다운로드 버튼을 눌러 day7_meeting_notes.md 파일을 automation/ 폴더 내에 저장합니다.
  2. 품질 오디팅 위임: Codex Client 입력창에 아래 **Codex 요청 프롬프트**를 전달해 종합 완숙도 검사를 실행합니다.
  3. 보고서 저장: AI가 점수 평가와 함께 제시해 준 로딩 스피너 및 에러 복원 우선순위 결과서(`day7_service_audit.md`)를 정리해 로컬에 보관합니다.
