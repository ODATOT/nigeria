Mission 01. AI와 함께 오류 해결하기 (Error Troubleshooting)

서버 호출 및 JSON 가공 중 발생한 CORS 및 파싱 오류를 AI와 함께 파고들며 오류 리포트를 기록합니다.

💾 실습 출력 (Output)

1. 스토리 및 실습 배경

대시보드 화면 프로토타입 작성 후 API 데이터 fetch 기능을 구현하여 가상의 서버 연동을 테스트하던 도중 예기치 못한 에러가 연쇄적으로 발생하였습니다. 해당 에러에 대해 Codex의 진단 처방을 받아 에러 요인을 추적하고, 최종적으로 안정적으로 구동되는 결과물을 입증합니다.

2. 학습 목표

  • 가상 서버 호출 시 발생하는 HTTP Status 404 및 CORS 장애 현상을 식별한다.
  • Response의 JSON 포맷이 깨졌을 때 발생하는 SyntaxError의 근본적 파싱 원인을 이해한다.
  • 디버깅 결과 조치 내역과 향후 재발 방지책을 정리한 오류 리포트를 작성한다.

🛠️ 실제 따라 하기 실습 가이드

  1. 실습용 파일 생성: 아래 다운로드 버튼을 눌러 day6_meeting_notes.md 파일을 automation/ 폴더 내에 저장합니다.
  2. CORS/JSON 파싱 진단: Codex Client에 수집한 에러 문장과 내 원본 코드를 넘겨주어 문제의 구조적 인과관계를 설명하도록 유도합니다.
  3. 오류 리포트 영구화: AI가 진단하고 제안한 수정 코드 가이드라인을 토대로 에러 리포트 양식(`day6_error_report.md`)을 작성하고 확인합니다.

5. AI 활용 포인트

  • CORS/파싱 원인 분석: 서버와 클라이언트 간의 도메인 차이 또는 HTTP 응답 내용의 타입 차이를 대조 분석합니다.
