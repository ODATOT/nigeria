Day 9 Summary

오늘의 핵심 목표

Day 9에서는 Codex AI 결제 파트너와 협업하여 사용자 이탈을 유발하는 단절 지점을 분석하고, 금융 에러 완화 문안과 중복 결제 차단 및 신뢰도 배지를 보완합니다.

  • 주문-결제 비즈니스 흐름 설계: 주문대기, 주문완료, 결제대기, 결제완료 등 상태 전이 설계
  • 외부 PG 연동 API 개발: PG사 SDK 및 API 연동을 통한 결제 요청/승인 처리
  • 웹훅 (Webhook) 데이터 검증: 결제 결과 위변조 방지를 위한 서버 간 Webhook 수신 및 대조
  • 트랜잭션(Transaction) 처리: 결제 처리 중 오류 발생 시 DB 롤백 및 주문 상태 원복
  • 결제 장애 복구 전략: 중복 결제 방지(Idempotency) 및 망취소 결제 처리
학습 팁: 오른쪽 AI 챗봇에게 “결제 완료 시 웹훅(Webhook)을 사용하는 이유와 보안상 검증 방법은 무엇인가요?” 또는 “결제 도중 네트워크 에러가 났을 때 데이터 무결성을 어떻게 보장하나요?” 같은 질문을 해보세요.
