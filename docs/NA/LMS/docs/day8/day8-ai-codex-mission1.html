1. 스토리 및 실습 배경

자체 제작한 회원 페이지에 가상 실버 사용자 페르소나를 투입하여 모의 온보딩 시범 주행을 수행합니다. 사용자는 '비밀번호를 입력하래서 정성껏 적었는데 빨간 글씨로 자꾸 안 된대요. 대문자가 빠졌다는데 입력할 땐 알려주지도 않아서 화가 납니다'라며 답답함을 토로했습니다. 사용자가 마찰을 겪는 동선을 조사해 실시간 친화적 알림 인디케이터와 blur 시점 자동 중복 검사로 전환하는 요구서를 마련합니다.

2. 학습 목표

  • 초보 사용자 관점의 특성에 맞춰 회원 가입 과정의 인지 부하 요소를 시뮬레이션할 수 있다.
  • 실시간 규칙 충족 피드백 부재로 인한 심리적 가입 장벽 문제를 진사하여 UX 교정 포인트를 마련할 수 있다.
  • 이메일 입력창 포커스 아웃 시점에 비동기로 중복 여부를 자동 감지하는 blur 개선 시나리오를 설계할 수 있다.

3. Codex AI 프롬프트 카드

아래의 프롬프트를 복사하여 Codex Client의 AI 질의 응답 창에 붙여넣고 가이드를 받으세요.

당신은 모바일 스마트 기기 가입에 어려움을 겪는 60대 초보 회원입니다. 화면 폼 기획 스펙 상의 가입 단계를 사용한다고 가정할 때, 당신의 입장에서 가입 중 불편하고 가로막히는 마찰 지점을 진사해 실시간 텍스트 유효 알림 개선 요구서(First User Review)를 도출해 주세요.
