학습 개요

Day 3는 앞선 화면 설계와 데이터 흐름 설계를 실제 데이터베이스 구조로 연결하는 단계입니다. 참가자는 화면과 사용자 흐름에서 필요한 데이터를 추출하고, 이를 엔티티와 속성 단위로 정리하게 됩니다.

이후 엔티티 간 관계를 정의하고, 1NF부터 3NF까지의 정규화 과정을 적용하여 중복을 줄이고 무결성을 높인 데이터 구조를 설계합니다. 최종적으로는 서비스 구현에 활용 가능한 ERD를 완성합니다.

이 과정에서 Codex AI를 프로젝트 아키텍트 및 감사자(Auditor)로 활용하여, 기획-개발 간 데이터 정렬(Task 01), 프로젝트 전반의 용어 표준 사전 구축(Task 02), 스키마 수정에 따른 연쇄 영향도 분석(Task 03)을 자동화하고, 기술 아키텍처 결정을 기록하는 DDL 작성(Mission 01) 및 동시성/무결성 오류 등의 예외 케이스 발굴(Mission 02)을 수행합니다.
