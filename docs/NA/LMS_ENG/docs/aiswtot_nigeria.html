Data Normalization & ERD Design

Structure the necessary data based on screen design and user flow, This is the third day of the learning module that defines key entities and relationships to complete a normalized data structure and ERD.

Day 3 is the step of connecting the previous screen design and data flow design to the actual database structure. Participants will extract the necessary data from screens and user flows and organize it into entities and properties.

Afterwards, the relationships between entities are defined and the normalization process from 1NF to 3NF is applied to Design data structures that reduce redundancy and increase integrity. Ultimately, we complete an ERD that can be used for service implementation.

Main session structure

Session 1 · 2 hours
Understand ERD design and extract data

Identify what data is needed based on screens and user flows, Organize this into structurable data items.

  • Screen and user flow-based data extraction
  • Define and group data fields
  • Understand the concept and purpose of ERD
Session 2 · 3 hours
Entity/Relationship Definition and Normalization Practice

Convert the extracted data into entities, define key relationships, and Design efficient data structures through the normalization process.

  • Define core entities and properties
  • 1:1, 1:N, N:M relationship settings
  • Apply 1NF → 2NF → 3NF normalization
Session 3 · 1 hour
ERD review and sharing of results

Share the completed data structure and ERD, We also review the appropriateness of deduplication and relationship establishment.

  • ERD diagram presentation
  • Review of normalization results
  • Summary of feedback-based correction points
