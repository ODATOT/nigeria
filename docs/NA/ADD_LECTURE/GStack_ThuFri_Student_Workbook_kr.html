02일 스프린트의 핵심 명제

내일 평가 기준은 “무엇을 만들었는가”가 아니라 “무엇을 새로 발견했는가”입니다.
데모 시연은 주인공이 아니라 증거 자료에 불과합니다.

탈락하는 발표

화면은 화려하지만 “누가 쓸지는 아직 찾아보는 중입니다…”

합격하는 발표

화면은 투박하지만 “실제 사용자 2명에게 물어보니 내 가설이 틀렸음을 확인했습니다”

솔직히 말씀드리면 — 이는 본 교육과정 범위를 넘어섭니다

비즈니스 모델 이론은 본 교육과정 평가 항목이 아닙니다. BM 이론으로 점수를 매기지 않습니다.

대신 평가하는 것은 문제를 얼마나 날카롭게 정의했는가 / 현실의 사용자를 직접 만났는가 / 한계를 솔직하게 밝혔는가입니다. 오늘 배우는 것은 스타트업 창업론이 아니라 AI를 활용해 판단의 질을 높이는 방법입니다. 이것이 바로 우리 수업의 핵심 목표입니다.

구축 비용이 0으로 수렴할수록, 모든 가치는 무엇을 만들지 선택하는 능력으로 이동합니다.

오해하지 마세요. “작게 만든다”는 것은 최소 기능(Minimum)을 의미하지 부실함(Mediocre)을 뜻하지 않습니다. 1개 화면으로 축소하되, 빈 상태(Empty State)와 오류 처리까지 완성도 높게 갖춰야 합니다.
