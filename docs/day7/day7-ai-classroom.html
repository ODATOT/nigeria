개발 (AI와 함께 기능 완성하기) 학습도우미

화면만 만들어져 있다고 서비스가 동작하는 것은 아닙니다. 사용자가 버튼을 누르면 데이터가 저장되고, 조회되고, 수정되는 기능이 함께 동작해야 합니다. 특히 본 세션에서는 Codex Client Workspace를 활용하여 정적 마크업에 이벤트를 매핑하고(Task 01), 필터가 유실되는 등 단절되는 유저 동선을 세션 스토리지를 활용하여 검증·보완하며(Task 02), 버튼 연타와 날짜 경계선 오류를 차단하는 기능 검증(Task 03)을 통해 온전히 가동되는 서비스를 조립합니다.

대상: 화면 뼈대 설계를 완료한 학생
준비물: 노트북, VS Code, 웹 브라우저
구성: 2시간 이론 / 3시간 실습 / 1시간 공유

Day 7 Summary

오늘의 핵심 목표

Day 7에서는 프론트엔드에서 호출한 API가 서버에서 어떻게 처리되는지 이해하고, Express.js 기반의 MVC 및 4계층 구조를 바탕으로 실제 CRUD API를 구현합니다.

  • Express.js 프로젝트 구성: RESTful API 설정을 위한 서버 환경 및 라우팅 설정
  • 계층형 아키텍처 설계: Route -> Controller -> Service -> Repository 구조 분리
  • 데이터베이스 CRUD 구현: ORM 또는 raw SQL을 이용한 데이터 CRUD 로직 작성
  • RESTful API 엔드포인트 개발: URI 설계 가이드라인에 부합하는 REST API 완성
  • 예외 처리 및 미들웨어 적용: 비즈니스 에러 및 전역 에러 핸들러 구성
학습 팁: 오른쪽 AI 챗봇에게 “계층형 아키텍처에서 Controller와 Service의 역할 분담을 어떻게 해?” 또는 “Express.js에서 전역 에러 핸들러 미들웨어를 어떻게 설정해?” 같은 질문을 해보세요.
