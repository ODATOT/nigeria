1. 스토리 및 실습 배경

실제 고객이 앱스토어에서 앱을 받아 최초로 서비스를 열고 최종 예약을 마무리 짓기까지의 단절 없는 시나리오(End-to-End)를 Codex의 페르소나와 챗 형식으로 시뮬레이션하면서, 끊김 없이 흐르는 무결점 서비스를 최종 입증합니다.

2. 학습 목표

  • 가입에서 목록 검색, 결제 회귀까지 단절 없는 사용자 시나리오(E2E)를 구성한다.
  • 디지털 기기 사용이 다소 어색한 고연령 페르소나의 인지 장벽 의견을 경청한다.
  • NG(오류) 지점을 개선하고 완주 가능한 시나리오 검증서(`day7_e2e_validation.md`)를 빌드한다.

🛠️ 실제 따라 하기 실습 가이드

  1. 실습용 파일 생성: 아래 다운로드 버튼을 눌러 day7_meeting_notes.md 파일을 automation/ 폴더 내에 저장합니다.
  2. 페르소나 역할 롤플레잉: Codex Client에게 '스마트폰 사용이 낯선 50대 자영업자 페르소나'를 지시하고 여정 시나리오 검증 테스트 대화를 나눕니다.
  3. 검증 결과서 작성: 동선 중 불편을 느낀 가입 정보 복원 에러 가드를 수정하고 최적화 상태 매트릭스를 기재한 종합 검증 결과서(`day7_e2e_validation.md`)를 빌드합니다.
