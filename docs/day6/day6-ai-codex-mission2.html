Mission 02. AI 코드 리뷰 받기 (AI-Assisted Code Quality Review)

작성한 최종 코드를 AI 객관식 평가지표에 따라 검토받고 캡슐화 및 최적화가 반영된 고품질 소스코드를 입증합니다.

💾 실습 출력 (Output)

1. 스토리 및 실습 배경

학습자가 대시보드 예약 제어 로직을 구현하며 다소 두서없이 임시로 적었던 최종 소스코드를 Codex에게 전문 코드 검토관(Code Reviewer) 자격으로 전체 감사(Audit)를 받도록 요청하고, 지적받은 개선 권고를 수정 코드에 완전히 수렴하여 고품질의 코드 리팩토링 버전을 제출합니다.

2. 학습 목표

  • 작성 완료한 코드를 AI 객관식 평가지표(가독성, 중복도, 캡슐화 등)에 따라 엄격히 진단받는다.
  • 전역 변수의 네임스페이스 오염 우려 및 연산 복잡도 지적사항을 이해한다.
  • 피드백에 근거해 소스코드를 캡슐화 모듈 형식으로 업데이트하고 리뷰 노트를 빌드한다.

🛠️ 실제 따라 하기 실습 가이드

  1. 실습용 파일 생성: 아래 다운로드 버튼을 눌러 day6_meeting_notes.md 파일을 automation/ 폴더 내에 저장합니다.
  2. 다면 코드 리뷰 요청: Codex Client에 소스 코드를 전송하여 변수명 가독성, 중복 로직 유무, 전역 오염 방지 측면의 리뷰를 지시합니다.
  3. 캡슐화 소스 저장: AI 지적사항을 토대로 개선한 모듈형 최종 수정본과 함께 코드 리뷰 피드백 결과서(`day6_code_review.md`)를 작성해 보관합니다.
